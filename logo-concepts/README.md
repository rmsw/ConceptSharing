# Rainmaker Software — Logo Concepts

Scratch folder for iterating on the Rainmaker Software trademark. Not
linked from any page on the site — the currently-live mark is
`wwwroot/img/rainmaker-software-logo.svg` (Concept A below), shown at
the bottom of the home hero.

## Preview

Run the app and browse to
[`/design/logo-concepts/index.html`](/design/logo-concepts/index.html)
(e.g. `http://localhost:5008/design/logo-concepts/index.html`). It's a
static page with no build step — opening `index.html` straight from the
filesystem also works. Each concept is rendered at:

- **16 px** (favicon)
- **1.35 em** (inline in a real "Authored by [logo] Rainmaker Software™" line)
- **64 px** (small marketing / card)
- **192 px** (marketing hero)

...on both a dark background (the site's deep-space palette) and a warm
off-white, plus a "gold on near-black" and "solid black on white" pass
to confirm each mark re-tints cleanly.

## Conventions

- 32×32 `viewBox`, so the mark reads as a single glyph at body text size.
- `fill="none"` + `stroke="currentColor"` for outlines; `fill="currentColor"` for weighted
  elements. This means the mark inherits its color from the surrounding
  text, so one file works on light + dark + warm palettes.
- No gradients, no filters, no external references — each SVG is
  self-contained and optimizer-friendly.
- Stroke widths sit around 1.5–1.6 units (≈5% of the viewBox) so the
  mark holds up down to 14–16 px without pixel-snapping tricks.
